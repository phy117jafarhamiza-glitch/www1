# AI-NeckRehab — نظام متكامل لتأهيل الرقبة (أداة مساندة لأطروحة)

**نوع الذكاء الاصطناعي:** تعلّم عميق موجَّه (Supervised Deep Learning) بنموذج هجين + رؤية حاسوبية:
- M1 EMG-Net: شبكة CNN أحادية البعد (NumPy) لتصنيف جودة النشاط العضلي.
- M2: BlazePose (CNN مدرَّبة مسبقًا) + حساب هندسي لمدى الحركة، ومنه المدرّب الحركي المباشر.
- M3 Dose-Net: شبكة MLP تقترح المقاومة/التكرارات/المجاميع (تعلّم بالمحاكاة من وصفات الخبراء).
- M4: طبقة أمان قائمة على قواعد سريرية (ليست شبكة عمدًا).

## الصفحات (قائمة مقسّمة بـ st.navigation، تتطلب Streamlit ≥ 1.37)
- **إدارة الدراسة:** اللاعبون والمجموعات · القياسات T0–T3 · البرنامج والتمارين · تقرير اللاعب
- **التمرين والمتابعة:** المدرّب الحركي المباشر · جلسة التأهيل الذكية · الألم اللحظي وPPT
- **القياسات الخاصة:** مؤشر NMCI (التوازن العصبي العضلي + التحكم الحركي) · مدى الحركة بالكاميرا
- **التحليل والإعداد:** EMG والنماذج العصبية (تحليل + تدريب) · الإحصاء · النسخ الاحتياطي

ملفات الصفحات في مجلد `views/` (لا يُستخدم مجلد `pages/` بعد الآن).

## التشغيل
```
pip install -r requirements.txt
streamlit run app.py
```
> يستخدم هذا الإصدار قاعدة `data/neck_rehab_v2.db` (جداول جديدة تُنشأ تلقائيًا). القديمة من الإصدار الأول لا تُستخدم.

## المدرّب الحركي المباشر (صفحة 14)
- يحتاج `streamlit-webrtc` و`av` و`mediapipe`. البث المباشر قد يتأخر أو لا يتصل على Streamlit Cloud (WebRTC)؛ يُفضَّل تشغيله محليًا أثناء التجربة.
- التبويب «فيديو مسجَّل» يعمل دون بث مباشر.
- زوايا الكاميرا 2D تقريبية (خطأ قد يبلغ 5–10°): أثبت الصلاحية مقابل مقياس مرجعي (صفحة 5، تبويب التحقق).
- التمارين الإيزومترية (1، 2، 6، 7، 13، 17) لا تُتتبَّع بالكاميرا؛ تُتابَع بـ EMG/القوة/الضغط.
- cv2 لا يرسم العربية، فالتراكب على الفيديو أرقام وأشرطة، والرسائل العربية تظهر بجانبه.

## مؤشر NMCI (صفحتا 10 و11)
مؤشر مركّب من 0 إلى 100 يضم التماثل ونسب القوة والتحمل وعتبة الألم ونشاط EMG أثناء CCFT ودقة التتبع والسلاسة (SPARC) والتحكم الاتجاهي. **الحدود مبدئية**، حدّدها من مجموعة ضابطة سليمة أو من الأدبيات قبل الاعتماد عليه.

## تنبيهات مهمة
1. النماذج الافتراضية مدرَّبة على **بيانات تركيبية للعرض فقط**؛ درّبها على بيانات حقيقية موسومة (صفحة 4) وجمّدها قبل التجربة.
2. على Streamlit Cloud التخزين مؤقت: استخدم صفحة النسخ الاحتياطي (9) بانتظام.
3. الإحصاء في التطبيق استكشافي؛ التحليل النهائي (ANOVA مختلط/LMM، تعويض القيم المفقودة) يُجرى في SPSS/R، وحجم العينة يؤكده مختص إحصاء.
4. جرعات البرنامج وسقوف الأمان مقترحة وتُعتمد مع الخبراء والمشرف واللجنة الأخلاقية.
